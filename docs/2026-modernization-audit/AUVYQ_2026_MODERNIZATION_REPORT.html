2. Outdated dynamic rule capacity capped at 4,500 rules (Chrome 120+ allows 30,000 rules).
3. Zero procedural cosmetic filtering (:has(), :has-text()).
4. RPC contention from content script frames flooding the background worker synchronously.

1. Trivial anti-adblock detection via window.__auvyq* globals in MAIN world and data-auvyq attributes.
2. Predictable hostname-seeded PRNG noise on canvas element readbacks.
3. declarativeNetRequestFeedback permission in manifest.json risking Chrome Web Store review rejection.
4. Bundled development ECDSA verification key in core/update-channel/channel.ts.
4 Biggest ad-blocking limitations?
1. The 217-rule limit leaves 95%+ of internet ads unblocked.
2. Inability to block or defuse Server-Side Ad Insertion (SSAI) in YouTube and video streams.
3. No query parameter tracking stripper ($removeparam).
4. Lack of an automated, signed remote rule update pipeline.
5 Missing important features?
1. Interactive Point-and-Click Visual Element Picker.
2. Automatic cookie consent (GDPR banner) rejection engine.
3. Real-time live network request visualizer on active tabs.
4. Edge machine learning risk model (activeRiskModel is currently null).
5. Firefox WebExtensions and Safari cross-browser compilation.

1. Remove declarativeNetRequestFeedback permission.
2. Remove CustomEvent DOM bridges (auvyq-scriptlets).
